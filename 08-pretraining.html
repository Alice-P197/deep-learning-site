第二部分 · 核心架构

预训练与自监督：从无标注数据中学习通用表示

标注数据昂贵，无标注数据近乎无限。自监督的核心思路是“从数据本身构造监督信号”： 预测下一个词、还原被遮住的部分、判断两个视图是否同源。预训练 + 微调，正是当代 AI 的标准配方。

8.1 预训练解决的是什么问题

监督学习要求每个样本都有标签，而标签的成本随任务复杂度急剧上升。自监督用数据自身的一部分 预测另一部分，把“无标签”变成“免费标签”，学到的表示再迁移到下游任务。

语言模型

用前文预测下一个 token，标签就是文本本身。

掩码重建

遮住一部分输入，让模型还原，逼它理解上下文。

对比学习

同一张图的两个增强视图应靠近，不同样本应远离。

为什么“预测下一个词”能学到知识

要准确预测下一个词，模型必须隐式掌握语法、事实、推理与风格。这个目标简单、可扩展、 且不需要人工标注，因此能吃到互联网规模的数据。

8.2 语言模型：CLM 与 MLM

因果语言建模（CLM / GPT 式）
LCLM = −Σt log pθ(xt| x<t)

只能看左侧上下文，天然适合生成。训练时一次前向即可对每个位置计算损失， 并行度高，是 Decoder-only LLM 的目标函数。

掩码语言建模（MLM / BERT 式）
LMLM = −Σi∈M log pθ(xi| x∖M)

随机遮住 15% 的 token，用双向上下文还原。适合理解类任务（分类、抽取、检索）， 但不能直接用于自回归生成。

维度BERT（Encoder-only）GPT（Decoder-only）
注意力双向，可见全部上下文因果，只能看左侧
目标MLM + NSP（原始版本）CLM
擅长分类、NER、检索、句子表示生成、对话、推理、few-shot
规模扩展中等规模更常见可扩展到万亿 token 与千亿参数
代表BERT、RoBERTa、DeBERTaGPT、LLaMA、Qwen、DeepSeek
下一 token 预测的概率分解

整段文本的概率被分解为每个位置的条件概率连乘： p(x1..T) = ∏ p(xt|x<t)。 这就是“自回归”的数学定义，也是所有生成式解码策略的基础。

8.3 对比学习：把相似样本拉近

对比学习不重建像素，而是学习一个度量空间。给定一个锚点样本，它的增强视图是正样本， 同一 batch 内其他样本是负样本。目标是正样本相似度高、负样本相似度低。

InfoNCE 损失
L = −log exp(sim(zi, zi+)/τ) Σj exp(sim(zi, zj)/τ)

分母包含正样本与所有负样本，本质是一个 (N+1) 分类问题。 τ 是温度，越小越关注困难负样本。batch 越大，负样本越多，效果通常越好。

CLIP：图文对比
sim(i,t) = f(I) · g(T)T ‖f(I)‖‖g(T)‖ / τ

一个 batch 内 N 对图文构成 N×N 相似度矩阵，对角线为正样本。 CLIP 学到的是跨模态共享空间，可直接做零样本分类与图文检索。

方法正样本构造是否需要负样本特点
SimCLR同一图像的两个增强是（batch 内）依赖大 batch 与强增强
MoCo同一图像的两个增强是（队列）动量编码器 + 记忆队列
BYOL / SimSiam同一图像的两个增强否预测器 + 停止梯度，避免坍缩
CLIP配对的图像与文本是（batch 内）跨模态、零样本能力强

8.4 掩码重建与视觉自监督

MAE（Masked Autoencoder）把图像切成 patch，随机遮住 75%，让 ViT 只从可见 patch 重建缺失部分。 由于编码器只处理可见 patch，训练效率很高，且迫使模型学习全局语义。

MAE 重建目标
L = 1 |M| Σi∈M ‖xi − x̂i‖2

只在被遮住的 patch 上计算损失。遮罩比例高会迫使模型使用上下文推理， 而不是从邻近像素插值。

重建 vs 对比

重建类方法（MAE、BEiT）关注细节还原，适合需要精细特征的任务； 对比类方法关注语义不变性，适合分类与检索。两者也常被组合使用。

8.5 迁移策略：从预训练到下游

策略训练参数数据需求适用场景
Linear probe只训练分类头很少评估表示质量、快速基线
Full fine-tune全部参数中等数据充足、任务与预训练接近
Adapter / LoRA少量新增或低秩参数较少多任务、多租户、显存有限
Prompt / Prefix提示向量极少少样本适配、冻结主干

经验法则：数据越少，越应该冻结更多参数；任务与预训练分布差得越远， 越需要放开深层参数。微调学习率通常比预训练小 1~2 个数量级。

8.6 代码：InfoNCE 与 MLM

Python · InfoNCE（CLIP 风格）
import torch
import torch.nn.functional as F

def clip_loss(img_emb, txt_emb, temperature=0.07):
    # 输入已做 L2 归一化，形状 (B, D)
    logits = img_emb @ txt_emb.t() / temperature        # (B, B)
    labels = torch.arange(logits.size(0), device=logits.device)
    loss_i = F.cross_entropy(logits, labels)            # 图找文
    loss_t = F.cross_entropy(logits.t(), labels)        # 文找图
    return (loss_i + loss_t) / 2

B, D = 8, 128
img = F.normalize(torch.randn(B, D), dim=-1)
txt = F.normalize(torch.randn(B, D), dim=-1)
print("clip loss:", clip_loss(img, txt).item())

# 对称 InfoNCE 的相似度矩阵对角线即正样本，
# 温度越小，模型越关注最难区分的负样本。
Python · 掩码语言建模损失
import torch
import torch.nn as nn

vocab, d_model = 1000, 64
mlm_head = nn.Linear(d_model, vocab)
hidden = torch.randn(4, 12, d_model)          # (B, T, D)
labels = torch.randint(0, vocab, (4, 12))
mask = torch.rand(4, 12) < 0.15                # 15% 被遮住
labels = torch.where(mask, labels, torch.full_like(labels, -100))  # 忽略未遮位置

logits = mlm_head(hidden)
loss = nn.functional.cross_entropy(
    logits.view(-1, vocab), labels.view(-1), ignore_index=-100
)
print("mlm loss:", loss.item())

# -100 是 PyTorch 的 ignore_index，未遮住的位置不贡献损失。
忽略位置用 -100

cross_entropy 默认 ignore_index=-100。 如果把未遮位置标成 0，会被当成“第 0 类”参与训练，损失完全失真。

8.7 本章小结

自监督的四种武器

  • CLM：预测下一个 token，适合生成，可扩展到极大规模。
  • MLM：还原被遮 token，双向理解，适合分类与抽取。
  • 对比学习：拉近正样本、推远负样本，学到可度量的表示空间。
  • 掩码重建：还原缺失部分，适合视觉与多模态的细节建模。
  • 预训练之后，按数据量选择 probe、全参微调或 LoRA。
  • 数据质量与去重，往往比模型结构更决定预训练效果。

常见误区

  1. 对比学习忘记 L2 归一化，相似度被向量模长主导。
  2. batch 太小导致负样本不足，对比效果大打折扣。
  3. MLM 的 ignore_index 设错，把非遮位置也计入损失。
  4. 微调学习率沿用过大的预训练值，把预训练知识冲掉（灾难性遗忘）。
  5. 只做一次预训练就固定不变，忽略数据分布与领域差异。
