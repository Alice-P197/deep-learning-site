训练与优化：让网络真正收敛

能写出模型不等于能训练出来。90% 的“模型不 work”出在优化器、学习率、 归一化与数据上。这一章给出可执行的训练配方，以及出现异常时按什么顺序排查。

4.1 训练循环的解剖

每个 step 都由五个动作组成，缺一不可。理解每个动作的副作用，比记住 API 更重要。

  1. 前向：把 batch 送进模型，得到 logits / 预测。此时会构建计算图（训练模式下）。
  2. 损失：把预测与标签比较，得到一个标量。损失必须是标量才能调用 backward。
  3. 清梯度：optimizer.zero_grad() 把上一步残留的梯度清零。
  4. 反向：loss.backward() 沿计算图求每个参数的梯度。
  5. 更新：optimizer.step() 按优化器规则修改参数。
梯度累积

显存不足时，把 batch 切成 k 份依次前向/反向，但只在第 k 次调用 step()。 注意损失要除以 k，否则梯度会放大 k 倍。这等效于更大的 batch。

4.2 优化器：从 SGD 到 AdamW

所有优化器都在回答两个问题：方向怎么定、步长怎么定。 SGD 用当前梯度，Momentum 用梯度的一阶动量，Adam 同时用一阶与二阶矩。

SGD 与 Momentum
vt = βvt−1 + ∇θL    θt+1 = θt − ηvt

动量让方向在一致时加速、在震荡时抵消，相当于给优化过程加了惯性。 Nesterov 变体先用动量走一步再算梯度，收敛略快。

Adam 的一阶与二阶矩
mt = β1mt−1 + (1−β1)gt    vt = β2vt−1 + (1−β2)gt2
θt+1 = θt − η m̂t √(v̂t) + ε

m̂、v̂ 是偏差修正后的矩估计。二阶矩让每个参数拥有自适应步长： 梯度一直很大的参数步子变小，稀疏更新的参数步子相对变大。

AdamW 的解耦权重衰减
θt+1 = θt − η(m̂t/(√v̂t + ε) + λθt)

原版 Adam 把 L2 混进梯度里，会被二阶矩缩放，导致大梯度参数的正则效果变弱。 AdamW 把权重衰减独立出来，是现代 Transformer 训练的默认选择。

优化器优点缺点典型场景
SGD简单、泛化好、显存省对学习率敏感、收敛慢CNN 大规模训练
Momentum抑制震荡、加速收敛多一个超参传统视觉任务
Adam自适应、易上手偶发泛化略差、显存多Transformer、小数据
AdamW正则与自适应解耦仍需调 lr / wd大模型默认

4.3 学习率：最重要的超参数

学习率决定每一步走多远。实践中几乎总是配合调度器：先热身（warmup）再衰减， 避免训练初期因初始化不稳而发散。

余弦退火 + 线性热身
ηt = ηmin + (ηmax − ηmin)2 (1 + cos(πt T))    t < twarm 时线性升到 ηmax

热身的目的是让模型先“站稳”，再全速前进；余弦衰减让后期步长平滑减小， 有助于收敛到更平坦的极小值。

Python · 学习率调度
import torch
from torch.optim.lr_scheduler import CosineAnnealingLR, LinearLR, SequentialLR

model = torch.nn.Linear(10, 2)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

warmup = LinearLR(opt, start_factor=0.1, total_iters=100)
cosine = CosineAnnealingLR(opt, T_max=900, eta_min=1e-5)
sched = SequentialLR(opt, schedulers=[warmup, cosine], milestones=[100])

for step in range(1000):
    opt.zero_grad()
    loss = model(torch.randn(8, 10)).pow(2).mean()
    loss.backward()
    opt.step()
    sched.step()                       # 每个 step 更新一次学习率
    if step % 200 == 0:
        print(step, opt.param_groups[0]["lr"])
学习率与 batch size

Batch 变大 k 倍时，梯度噪声下降，可用更大的学习率（线性缩放规则）。 但超过一定 batch 后收益递减，需要配合 warmup 与更长的训练。

4.4 归一化：让每层输入分布稳定

内部协变量偏移会让深层网络难以训练。归一化把每层输入拉回零均值、单位方差， 再加两个可学习参数恢复表达能力。

BatchNorm（训练时，按特征维统计）
μ = 1N Σixi    σ2 = 1 NΣi(xi − μ)2
x̂ = (x − μ)/√(σ2 + ε)    y = γx̂ + β

BN 依赖 batch 统计：batch 太小或序列长度变化时不稳定。 LayerNorm 改为对每个样本的所有特征归一化，与 batch 无关，是 Transformer 的标准选择。

方法统计维度适用注意事项
BatchNormbatch + 空间维CNN、大 batch小 batch 不稳定；训练/推理行为不同
LayerNorm单样本特征维Transformer、RNN与 batch 无关，稳定
RMSNorm均方根LLaMA 等大模型省去均值计算，更快
GroupNorm通道分组小 batch 视觉检测/分割常用
train / eval 必须切换

BN 在训练时用当前 batch 统计并更新滑动均值，推理时用滑动均值。 忘记 model.eval() 会让验证结果随机波动。

4.5 正则化与稳定训练技巧

  • Weight decay：L2 惩罚，AdamW 中解耦；视觉任务常设 1e-4 ~ 5e-2。
  • Dropout：训练时以概率 p 置零并用 1/(1−p) 缩放，推理时关闭。
  • Label smoothing：把 one-hot 标签软化为 (1−ε) 与 ε/(C−1)，抑制过度自信。
  • Mixup / CutMix：混合样本与标签，提升视觉任务泛化。
  • 梯度裁剪：把梯度范数限制在阈值内，防止个别 batch 炸掉训练。
  • 早停：验证指标连续若干 epoch 不提升就停止，并回滚最佳权重。
全局梯度裁剪
if ‖g‖ > c: g ← g · c/‖g‖

clip_grad_norm_(params, max_norm=1.0) 只改变方向不变的步长缩放， 在 RNN、Transformer 与强化学习里几乎是必选项。

Dropout 的期望保持
rj ~ Bernoulli(1−p)    yj = rjxj 1 − p

缩放保证训练与推理的激活期望一致（inverted dropout）。 推理时直接使用 x，不需要再乘系数。

4.6 混合精度、显存与吞吐

现代 GPU 的 FP16 / BF16 吞吐远高于 FP32。混合精度用低精度做矩阵运算、用 FP32 维护主权重， 配合损失缩放避免梯度下溢。

Python · AMP + 梯度累积 + 裁剪
import torch

model = torch.nn.Linear(64, 10).cuda()
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
scaler = torch.cuda.amp.GradScaler()
accum_steps = 4

for step, (x, y) in enumerate(loader):
    with torch.autocast(device_type="cuda", dtype=torch.float16):
        logits = model(x)
        loss = torch.nn.functional.cross_entropy(logits, y) / accum_steps

    scaler.scale(loss).backward()                 # 放大损失再反向

    if (step + 1) % accum_steps == 0:
        scaler.unscale_(opt)                      # 反缩放后才能裁剪
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        scaler.step(opt)
        scaler.update()
        opt.zero_grad(set_to_none=True)
显存都去哪了

参数 + 梯度 + 优化器状态（Adam 每个参数额外两份）+ 激活值。前三者与参数量成正比， 激活值与 batch、序列长度、层数成正比。省显存优先降 batch、用梯度检查点、换 8-bit 优化器。

4.7 训练异常诊断表

现象可能原因先做什么
loss 变 NaN学习率过大、除零、log(0)、混合精度溢出降 lr 10 倍，检查损失实现，开梯度裁剪
loss 不降标签错位、学习率过小、优化器没 step、数据全零在 1 个 batch 上过拟合，打印输入与标签
训练降 / 验证升过拟合或分布偏移加数据、加增强、加正则、早停
验证远差于训练BN 未切换 eval、数据泄漏反向、预处理不一致检查 eval 模式与验证管线
loss 剧烈震荡lr 过大、batch 太小、梯度爆炸warmup、降 lr、梯度裁剪
显存 OOMbatch 太大、未 no_grad、缓存未释放降 batch、加 no_grad、del 中间变量
万能第一步：过拟合一个小 batch

取 8~32 个样本，关掉正则，训练到 loss 接近 0。如果做不到，问题一定在模型或数据管道， 而不是超参数。这一步能在几分钟内排除一半的可能性。

4.8 代码：一个完整可复用的训练循环

Python · 训练模板
import torch
from torch.utils.data import DataLoader

def train_one_epoch(model, loader, opt, sched, scaler, device, accum=1):
    model.train()
    total, correct, loss_sum = 0, 0, 0.0
    opt.zero_grad(set_to_none=True)

    for step, (x, y) in enumerate(loader):
        x, y = x.to(device, non_blocking=True), y.to(device, non_blocking=True)
        with torch.autocast(device_type=device.type, enabled=scaler.is_enabled()):
            logits = model(x)
            loss = torch.nn.functional.cross_entropy(logits, y) / accum

        scaler.scale(loss).backward()
        if (step + 1) % accum == 0:
            scaler.unscale_(opt)
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            scaler.step(opt)
            scaler.update()
            opt.zero_grad(set_to_none=True)
            if sched is not None:
                sched.step()

        loss_sum += loss.item() * accum * y.size(0)
        correct += (logits.argmax(1) == y).sum().item()
        total += y.size(0)

    return loss_sum / total, correct / total

@torch.no_grad()
def evaluate(model, loader, device):
    model.eval()
    total, correct, loss_sum = 0, 0, 0.0
    for x, y in loader:
        x, y = x.to(device), y.to(device)
        logits = model(x)
        loss_sum += torch.nn.functional.cross_entropy(logits, y, reduction="sum").item()
        correct += (logits.argmax(1) == y).sum().item()
        total += y.size(0)
    return loss_sum / total, correct / total
注意 reduction

评估时用 reduction="sum" 再除以样本总数，避免最后一个不满 batch 被等权平均造成偏差。

4.9 本章小结

训练配方（按优先级）

  • 先保证数据与损失正确，用一个小 batch 验证可过拟合。
  • 默认 AdamW + 余弦退火 + warmup；视觉大任务可试 SGD + Momentum。
  • 学习率是最敏感的超参，先粗搜再精调。
  • 归一化位置与类型要和架构匹配：CNN 用 BN，Transformer 用 LN/RMSNorm。
  • 梯度裁剪、混合精度、梯度累积是工程标配。
  • 训练异常先看曲线形状，再按诊断表逐项排除。

常见误区

  1. 把 weight decay 与 L2 在 Adam 中当成完全等价（应使用 AdamW）。
  2. 学习率调度按 epoch 更新却按 step 记录，导致实际 lr 错位。
  3. 验证时忘记 model.eval()，BN 与 Dropout 行为错误。
  4. 梯度累积时忘记把 loss 除以累积步数。
  5. 混合精度下未使用 GradScaler，梯度下溢成 0。
