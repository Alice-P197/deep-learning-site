注意力与 Transformer：现代深度学习的底座

Transformer 用一个极其简单的操作——按相关性加权求和——替代了循环与卷积， 换来全局感受野与高度并行。今天的大语言模型、视觉骨干、多模态系统几乎都长在这套结构上。

7.1 注意力的直觉：查字典

把每个 token 想象成一次查询（Query）。它在序列里寻找与自己相关的键（Key）， 根据匹配程度取回对应的值（Value）。与 RNN 不同，任意两个位置之间只隔一次注意力， 路径长度是 O(1)，且所有位置可以同时计算。

缩放点积注意力
Attention(Q,K,V) = softmax(QKT √dk)V

QKT 得到相似度矩阵 (T, T)，softmax 归一化成权重，再对 V 加权。 除以 √dk 是因为点积方差随维度增长，不缩放会让 softmax 饱和、梯度消失。

因果掩码
Aij = softmaxj( QiKjT/√d + Mij),    Mij = −∞ if j > i else 0

生成模型不能让位置 i 看到未来，因此在 softmax 前把上三角置为 −∞， 归一化后这些位置权重为 0。训练与推理都靠它保证自回归性。

7.2 多头注意力

单头注意力只有一种“相关性视角”。多头把表示切成 h 份，每份独立做注意力， 再拼接投影。不同头可以分别关注语法、指代、位置等不同模式。

多头注意力
headi = Attention(QWiQ, KWiK, VWiV)
MultiHead(Q,K,V) = Concat(head1, …, headh)WO

通常 dk = dmodel/h，保证总计算量与单头相当。 每个头有自己的 Q/K/V 投影矩阵，输出再经 WO 融合。

自注意力、交叉注意力与三种用法
Self-Attn: Q=K=V=X    Cross-Attn: Q=Xdec, K=V=Xenc

编码器用自注意力；解码器先用带掩码的自注意力，再对编码器输出做交叉注意力。 这就是原始 Transformer 的 encoder–decoder 结构。

注意力的成本

QKT 是 T×T 矩阵，时间与显存都是 O(T²)。序列翻倍，注意力成本变四倍。 这是长上下文的核心瓶颈，也是 FlashAttention、稀疏注意力、线性注意力的动机。

7.3 位置编码：注意力本身没有顺序

注意力对输入顺序是置换不变的：打乱 token 顺序，输出只是跟着打乱。必须显式注入位置信息。

正弦位置编码
PE(pos, 2i) = sin(pos/100002i/d)    PE(pos, 2i+1) = cos(pos/100002i/d)

不同频率的正弦波让每个位置有唯一编码，且相对位移可被线性变换表示。 优点是无需训练、可外推到更长序列（有限）。

旋转位置编码 RoPE
qm = Rmq,    kn = Rnk    ⇒   qmTkn = qTRn−mk

把 Q/K 按位置旋转，使内积只依赖相对位置 n−m。RoPE 是现代 LLM （LLaMA、Qwen 等）的主流方案，便于长度外推。

7.4 Transformer Block 的解剖

一个 block 由两个子层组成：多头注意力 + 前馈网络（FFN）。每个子层都带残差与归一化。 现代实现几乎都采用 Pre-LN：先归一化再进子层，残差直通。

Pre-LN Block
x′ = x + Attn(LN(x))    y = x′ + FFN(LN(x′))

Post-LN 在残差后归一化，深层训练需要 warmup 才稳定；Pre-LN 把归一化放在分支内， 梯度直通路径更干净，是大模型的标准做法。

前馈网络（逐位置）
FFN(x) = W2 φ(W1x + b1) + b2

隐藏维通常是 dmodel 的 4 倍（LLM 中常用 8/3 倍的 SwiGLU 变体）。 FFN 占 block 参数量的约 2/3，是“知识存储”的主要位置。

Python · 手写多头注意力
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=256, n_heads=8, dropout=0.1):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_model, self.h = d_model, n_heads
        self.dk = d_model // n_heads
        self.qkv = nn.Linear(d_model, 3 * d_model, bias=False)
        self.out = nn.Linear(d_model, d_model, bias=False)
        self.drop = nn.Dropout(dropout)

    def forward(self, x, causal=False):
        B, T, C = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        # (B, T, C) -> (B, h, T, dk)
        q, k, v = [t.view(B, T, self.h, self.dk).transpose(1, 2) for t in (q, k, v)]

        scores = q @ k.transpose(-2, -1) / math.sqrt(self.dk)      # (B, h, T, T)
        if causal:
            mask = torch.triu(torch.ones(T, T, device=x.device, dtype=torch.bool), 1)
            scores = scores.masked_fill(mask, float("-inf"))
        attn = self.drop(F.softmax(scores, dim=-1))
        out = attn @ v                                             # (B, h, T, dk)
        out = out.transpose(1, 2).contiguous().view(B, T, C)
        return self.out(out), attn

class Block(nn.Module):
    def __init__(self, d_model=256, n_heads=8, mult=4, dropout=0.1):
        super().__init__()
        self.ln1 = nn.LayerNorm(d_model)
        self.attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.ln2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, mult * d_model), nn.GELU(),
            nn.Linear(mult * d_model, d_model), nn.Dropout(dropout),
        )

    def forward(self, x, causal=False):
        a, _ = self.attn(self.ln1(x), causal=causal)
        x = x + a
        return x + self.ffn(self.ln2(x))

block = Block()
x = torch.randn(2, 16, 256)
print(block(x, causal=True).shape)      # (2, 16, 256)

7.5 复杂度、KV Cache 与架构变体

操作时间复杂度显存说明
自注意力O(T² d)O(T²)长序列的瓶颈
FFNO(T d²)O(T d)短序列时占主导
KV Cache每步 O(T d)O(T d) 每层避免重复计算历史 K/V

自回归生成时，历史 token 的 K、V 不会改变，可以缓存起来，每步只计算新 token 的 Q， 把每步复杂度从 O(T²) 降到 O(T)。代价是显存：缓存大小约为 2 × 层数 × 头数 × 头维 × 序列长度 × batch × 字节数。

KV Cache 显存估算
mem ≈ 2 · L · H · dk · T · B · bytes

例：32 层、32 头、头维 128、序列 4096、batch 8、FP16（2 字节） ≈ 2×32×32×128×4096×8×2 ≈ 16 GB。这还没算权重与激活。

效率改进

FlashAttention（分块减少显存访问）、GQA/MQA（多个 Query 共享 K/V）、 稀疏与滑动窗口注意力、线性注意力。

架构变体

Encoder-only（BERT）、Decoder-only（GPT/LLaMA）、Encoder–Decoder（T5）。 今天的主流 LLM 几乎都是 Decoder-only。

7.6 本章小结

Transformer 必记要点

  • 注意力 = 相似度 + softmax + 加权求和，路径长度 O(1)。
  • 缩放因子 √dk 防止点积过大导致 softmax 饱和。
  • 因果掩码保证生成时看不到未来。
  • 多头让模型同时学习多种相关性模式。
  • 位置编码必不可少，RoPE 通过旋转实现相对位置。
  • Pre-LN + 残差 + FFN 是现代 block 的标准配置。
  • KV Cache 把生成复杂度从 O(T²) 降到 O(T)，代价是显存。

常见误区

  1. 忘记缩放 √dk，训练初期 loss 卡住不降。
  2. 因果掩码用 0 而不是 −∞，softmax 后仍会泄漏未来信息。
  3. 多头切分时维度顺序写错，把 head 维与序列维混淆。
  4. 以为注意力自带顺序，省略位置编码。
  5. 训练时用 causal 掩码、推理时忘记，导致训练/推理行为不一致。
