数学基础：读懂深度学习公式的语言

深度学习不是一堆公式的堆砌，而是三门语言的三次握手：线性代数描述“如何变换表示”， 微积分描述“如何修正参数”，概率论描述“如何在不确定中做判断”。这一章把后面 15 章真正会用到的 数学压缩成可操作的直觉。

1.1 为什么这些数学非学不可

你完全可以在不理解数学的情况下调用 model.fit()，但会遇到三类无法绕开的问题： 模型不收敛却不知道查哪里、看到论文公式就跳过、调参全靠玄学。数学的作用不是推导，而是让你在 出问题时知道该看哪一行。

线性代数

回答“数据长什么样、层与层之间怎么变换”。形状不匹配、维度对不上，几乎都在这。

微积分

回答“参数往哪个方向改”。反向传播本质是链式法则在计算图上的高效实现。

概率与信息论

回答“模型输出意味着什么”。分类损失、生成模型、不确定性都在这里。

学习建议：本章不要求手推所有公式。先建立“符号 → 形状 → 含义”的映射， 遇到不懂的公式再回来查对应小节。

1.2 张量：深度学习的唯一数据结构

标量是 0 维张量，向量是 1 维，矩阵是 2 维，彩色图片是 3 维（通道 × 高 × 宽）， 一个 batch 的图片是 4 维（batch × 通道 × 高 × 宽）。PyTorch 里所有计算都是张量运算， 读代码的第一件事永远是标注形状。

符号形状典型含义代码
x()标量损失torch.tensor(3.0)
x(C,)一个特征向量torch.randn(128)
X(N, C)N 个样本，每个 C 维torch.randn(64, 128)
X(N, C, H, W)图像 batchtorch.randn(32, 3, 224, 224)

广播与矩阵乘法

广播（broadcasting）让形状不同的张量按规则自动对齐：从最后一维开始比较，维度相等或其中一个为 1 即可扩展。它减少了显式复制，但也制造了大量“看起来能跑、其实算错了”的 bug。

矩阵乘法的形状规则
(N, D) · (D, M) → (N, M)

中间维度必须相等，结果保留外侧两个维度。神经网络里几乎每个线性层都是这一步： Y = XW + b。

Python · 形状与广播
import torch

x = torch.randn(4, 3, 32, 32)          # batch=4, 通道=3, 32x32
w = torch.randn(3, 3)                  # 形状不匹配，会报错
# 正确写法：把通道维换到最后一维再做线性映射
y = x.permute(0, 2, 3, 1) @ w          # (4, 32, 32, 3) @ (3, 3) -> (4, 32, 32, 3)

a = torch.tensor([[1.0], [2.0], [3.0]])  # (3, 1)
b = torch.tensor([10.0, 20.0])           # (2,) 广播为 (3, 2)
print((a + b).shape)                     # torch.Size([3, 2])

print(x.mean(dim=(0, 2, 3)).shape)       # 按通道求均值 -> (3,)
print(x.view(4, -1).shape)               # 展平空间维 -> (4, 3072)
工程习惯

在任何模型代码里，先写一行注释标明输入输出形状，例如 # x: (B, 3, 224, 224) -> (B, 1000)。这行注释能省掉一半调试时间。

1.3 线性代数：表示与相似度

线性层做的是仿射变换，注意力做的是向量内积，PCA 与 SVD 做的是找“主要方向”。 真正需要掌握的是四个概念：内积、范数、秩、特征分解。

内积与余弦相似度
x · y = Σi xiyi     cos θ = x · y‖x‖ ‖y‖

内积衡量方向一致程度。词向量、图像检索、对比学习都靠它：方向越接近，语义越相似。 余弦相似度对向量长度不敏感，适合比较归一化后的表示。

常见范数
‖x‖1 = Σi|xi|    ‖x‖2 = √(Σixi2)    ‖W‖F = √(ΣijWij2)

L1 促进稀疏（很多权重变 0），L2 抑制大幅值（权重整体变小）。 这就是 L1/L2 正则化在几何上的区别。

特征值、SVD 与“有效维度”

矩阵的秩说明它能把输入映射到多少独立方向。神经网络的表示学习，很多时候就是在寻找一个 低维流形：高维像素其实由少量语义因子控制。PCA 取最大特征值对应的方向， SVD 把任意矩阵分解为旋转—缩放—旋转，这两者常用于降维、压缩与 LoRA 的秩约束。

SVD 与低秩近似
A = UΣVT    Ak = Σi=1..k σiuiviT

只保留前 k 个奇异值即可用极少参数逼近原矩阵——这是模型压缩与低秩微调（LoRA）的数学依据。

1.4 微积分：梯度告诉你往哪走

训练模型就是最小化一个标量损失 L(θ)。 偏导数 ∂L/∂θi 表示“只把第 i 个参数动一点点， 损失会怎么变”。把所有偏导排成向量就是梯度，它指向损失上升最快的方向，因此沿负梯度走就能下降。

梯度下降更新
θt+1 = θt − η ∇θL(θt)

η 是学习率。步子太小收敛慢，太大则震荡甚至发散。 所有优化器（Momentum、Adam）本质上都在改写这一行的“方向”和“步长”。

链式法则 · 反向传播的骨架
∂L ∂x = ∂L ∂y · ∂y ∂x

若 y = f(x) 且 L 只通过 y 依赖 x， 上游传来的梯度乘以本层局部导数即可。多层堆叠时从后往前连乘，这就是 backprop。

多元情形与雅可比
Jij = ∂yi ∂xj    ∇xL = JT ∇yL

向量对向量求导得到雅可比矩阵。反向传播并不真的构造这个矩阵， 而是用“向量—雅可比积”一次算完，复杂度与一次前向相当。

关键直觉

梯度是“局部线性近似”的斜率。神经网络高度非线性，所以梯度只保证一小步内有效： 这就是学习率不能随便调大的根本原因。

1.5 概率：模型到底在输出什么

分类模型输出的不是“答案”，而是条件概率分布 p(y|x)。 训练就是让模型分布逼近真实分布；推理则是从这个分布里取最大概率或采样。

贝叶斯公式
p(y|x) = p(x|y)p(y) p(x)    p(x) = Σy p(x|y)p(y)

先验 × 似然 = 后验。生成模型建模 p(x|y)， 判别模型直接建模 p(y|x)。

最大似然：大多数损失的来源

给定数据集，我们希望模型给真实标签分配高概率。连乘容易下溢，取对数后变成求和， 于是“最大化对数似然”等价于“最小化负对数似然”。

最大似然估计（MLE）
θ* = argmaxθ Σi log pθ(yi|xi) = argminθ − Σi log pθ(yi|xi)

回归用高斯似然 → 均方误差；分类用伯努利/类别分布 → 二元/多元交叉熵。 损失函数不是随便发明的，几乎都能从似然推出来。

1.6 信息论：交叉熵与 KL 散度

熵衡量不确定性，交叉熵衡量“用模型分布 q 编码真实分布 p 的平均代价”。 由于真实分布的熵是常数，最小化交叉熵就等于最小化 KL 散度。

熵 · 交叉熵 · KL 散度
H(p) = −Σi pi log pi
H(p, q) = −Σi pi log qi    DKL(p‖q) = H(p, q) − H(p)

KL 非对称，不是距离。训练中常固定 p 为数据分布， 最小化 KL 即最小化交叉熵。DKL ≥ 0，等号仅当两分布相同。

Softmax 与数值稳定

多分类先用 logits 的指数归一化得到概率。直接取指数会溢出，实现时先减去最大值， 结果在数学上完全等价。

Softmax
softmax(z)i = ezi Σj ezj    实现时：z ← z − max(z)

Softmax 有温度参数 z/T： 温度高 → 分布更平（更随机），温度低 → 更尖锐（更确定），是采样策略的核心旋钮。

1.7 代码：把概念跑一遍

下面的脚本做三件事：验证广播规则、用数值差分检查梯度、验证交叉熵与 log-softmax 的一致性。 这三项是后续所有章节的“数学体检”。

Python · 数学体检
import torch
import torch.nn.functional as F

# 1) 广播：形状从右往左对齐，1 可以扩展
a = torch.arange(6.).view(2, 3)
b = torch.tensor([10., 20., 30.])
print("broadcast:", (a + b).shape)              # (2, 3)

# 2) 数值梯度：中心差分，用于验证手写反向传播
def f(x):
    return (x ** 3).sum()

x = torch.tensor([2.0, -1.0], requires_grad=True)
loss = f(x)
loss.backward()
auto = x.grad.clone()

eps = 1e-4
num = []
for i in range(x.numel()):
    xi = x.detach().clone()
    xi[i] += eps
    xj = x.detach().clone()
    xj[i] -= eps
    num.append((f(xi) - f(xj)) / (2 * eps))
print("auto:", auto, "numeric:", torch.tensor(num))  # 应几乎相等

# 3) 交叉熵 = NLL + log-softmax，torch 已融合成稳定实现
logits = torch.tensor([[2.0, 1.0, 0.1], [0.3, 2.5, 0.2]])
target = torch.tensor([0, 1])
print("ce:", F.cross_entropy(logits, target))
print("manual:", -(F.log_softmax(logits, dim=1)[range(2), target]).mean())

# 4) KL 非负且非对称
p = torch.tensor([0.7, 0.2, 0.1])
q = torch.tensor([0.5, 0.3, 0.2])
print("KL(p||q):", (p * (p / q).log()).sum())
print("KL(q||p):", (q * (q / p).log()).sum())
常见坑

loss.backward() 会累加梯度而不是覆盖。每个训练步必须 optimizer.zero_grad()，否则梯度会跨 step 叠加。

1.8 本章小结

应该带走的六件事

  • 张量的形状比数值更重要，读代码先读 shape。
  • 线性层 = 矩阵乘法 + 偏置；注意力 = 内积 + softmax + 加权求和。
  • 梯度指向损失上升方向，训练沿负梯度走；学习率决定步子。
  • 反向传播 = 链式法则 + 从后往前 + 复用中间结果。
  • 分类输出是概率分布；交叉熵来自最大似然，KL 衡量分布差异。
  • Softmax 必须做数值稳定处理，否则会溢出为 NaN。

初学者最容易踩的坑

  1. 把广播当成“自动对齐任意形状”——只有维数为 1 或相等时才能广播。
  2. 把 view 与 reshape 混用，遇到非连续内存就报错。
  3. 忘记梯度是累加的，导致 loss 突然爆炸。
  4. 用准确率评估类别不平衡的数据，得到 99% 却毫无意义。
  5. 以为 KL 是对称距离，写出方向错误的损失函数。
