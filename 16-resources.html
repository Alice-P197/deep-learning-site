16.1 三条路线，按你的起点选择

A

零基础转行

先补 Python 与线性代数，再走第 1~6 章，做一个图像分类项目， 最后进入第 7、12 章。周期约 4~6 个月。

B

有编程基础

快速过第 1、2 章，重点啃第 3~7 章的反向传播与注意力， 用 PyTorch 重写一遍核心模块。周期约 2~3 个月。

C

做工程落地

直接读第 4、8、12~14 章，重点是训练稳定性、微调与推理服务， 配合一个真实业务数据集。周期约 1~2 个月。

16.4 值得精读的论文

  1. AlexNet (2012)深度学习复兴的起点，理解 ReLU、Dropout 与数据增强。
  2. Batch Normalization (2015)训练稳定性的里程碑，理解内部协变量偏移。
  3. ResNet (2015)残差连接解决深层退化，是几乎所有现代网络的骨架。
  4. Adam (2014) / AdamW (2017)自适应优化器与权重衰减解耦。
  5. Attention Is All You Need (2017)Transformer 原始论文，必须手推一遍。
  6. BERT (2018) / GPT-2 (2019)两种预训练范式的代表。
  7. ViT (2020)把 Transformer 引入视觉，理解 patch 与归纳偏置。
  8. DDPM (2020) / Latent Diffusion (2021)扩散模型与潜空间生成。
  9. CLIP (2021)图文对比学习与零样本迁移。
  10. LoRA (2021) / InstructGPT (2022)低成本微调与人类反馈对齐。
  11. Chinchilla (2022)数据与参数的缩放配比。
  12. FlashAttention (2022)IO 感知的注意力实现，理解显存层次。
怎么读论文

第一遍只读标题、摘要、图和结论，判断是否相关；第二遍读方法与实验设置； 第三遍才推公式与复现。多数论文只需要第一遍。

16.5 项目清单：按难度分三档

入门档

MNIST/CIFAR 分类、IMDB 情感分析、房价回归、简单图像增强。 目标是把训练循环、评估、保存加载跑通。

进阶档

目标检测（YOLO 微调）、语义分割、文本摘要、语音识别微调、 推荐召回双塔。目标是对齐真实数据与指标。

挑战档

从零训练小语言模型、LoRA 微调 + DPO、扩散模型生成、 vLLM 部署与压测、RAG 问答系统。目标是完整链路与工程指标。

作品集建议

选 2~3 个能讲清“问题—数据—方法—指标—反思”的项目， 附可运行代码与实验记录，比堆十个半成品更有说服力。

16.7 环境自检

开始任何项目前，先确认框架、CUDA 与随机性设置正常。下面的脚本可以在新机器上快速排雷。

python · 环境自检 
import random

import numpy as np
import torch


def env_report() -> dict:
    """打印关键环境信息，并验证 GPU 上的前向反向是否正常。"""
    info = {
        "torch": torch.__version__,
        "cuda_available": torch.cuda.is_available(),
        "cuda_version": torch.version.cuda,
    }
    if info["cuda_available"]:
        info["device"] = torch.cuda.get_device_name(0)
        info["memory_gb"] = round(
            torch.cuda.get_device_properties(0).total_memory / 1024 ** 3, 1
        )

    # 固定种子并做一次最小训练回路
    random.seed(0)
    np.random.seed(0)
    torch.manual_seed(0)
    device = "cuda" if info["cuda_available"] else "cpu"

    model = torch.nn.Linear(4, 2).to(device)
    x = torch.randn(8, 4, device=device)
    y = torch.randint(0, 2, (8,), device=device)
    loss = torch.nn.functional.cross_entropy(model(x), y)
    loss.backward()

    grad_ok = model.weight.grad is not None
    info["grad_ok"] = grad_ok
    return info


if __name__ == "__main__":
    for key, value in env_report().items():
        print(f"{key:14s} {value}")

16.8 学习习惯与自查

  1. 先跑通再理解拿到新模型先跑官方示例，再逐层拆解， 比从公式开始更高效。
  2. 写实验日志每次实验记录假设、改动、结果与结论， 避免重复踩坑。
  3. 复现一篇论文完整复现一次，胜过读十篇综述。
  4. 关注失败案例负样本、边界输入、分布外数据往往决定系统上限。
  5. 定期回看基础反向传播、概率与优化，是长期竞争力的来源。

本章要点

  • 路线按起点选择，但“基础—架构—生成—工程”的顺序不可跳跃。
  • 每周一个可运行产出，是防止学习归零的最有效手段。
  • 论文分三遍读，多数只需第一遍。
  • 项目贵在讲得清，不在数量多。
  • 工具链服务于实验效率，不要为了工具而工具。

常见误区

  1. 收藏了几十门课程，却没有一个完整跑通的项目。
  2. 只学框架 API，不理解张量形状与梯度流动。
  3. 追新模型，忽略数据质量与评测设计。
  4. 从不读原始论文，只依赖二手解读。
  5. 把训练损失下降当成任务成功，忽略线上指标。
