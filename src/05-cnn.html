第二部分 · 核心架构

卷积神经网络：让模型看见局部结构

全连接层把图像当成一维向量，丢掉了空间结构且参数量巨大。卷积用局部连接、 权重共享和平移等变性，把“看见边缘 → 组合成部件 → 识别物体”的层次结构写进了架构里。

预计 60 分钟前置：第 3、4 章 关键词：感受野 · 残差 · 深度可分离卷积

5.1 为什么卷积有效

一张 224×224×3 的图像展平后是 150528 维，接一个 4096 维的全连接层就有 6 亿参数。 卷积通过三个先验把参数量降到可训练范围：

局部性

相邻像素相关，一个卷积核只看一个小窗口，不需要连接全部输入。

平移等变

同一个卷积核滑过全图，猫在左上或在右下都能被同一组权重检测到。

权重共享

整张图共用一套核参数，参数量与图像大小无关，只需学习“模式”本身。

二维互相关（深度学习中的“卷积”）
y[i,j] = ΣmΣn x[i+m, j+n] · w[m, n] + b

严格意义的卷积要翻转核，但框架实现的是互相关；因为核是学出来的， 翻不翻转只影响参数命名，不影响表达能力。

5.2 输出尺寸、padding、stride、dilation

卷积输出的空间尺寸由四个量决定：输入尺寸 H、核大小 K、填充 P、步长 S。 记不住公式时，用“能滑几步”推导即可。

输出空间尺寸
Hout = ⌊(Hin + 2P − D(K−1) − 1)/ S⌋ + 1

D 是膨胀率（dilation），让同样的核覆盖更大的范围而不增加参数。 “same” 填充通常取 P = (K−1)/2（S=1 时保持尺寸）。

配置作用常见取值
padding控制边界信息与输出尺寸3×3 核配 pad=1 保持尺寸
stride下采样，减小计算量2 使尺寸减半
dilation扩大感受野，保留分辨率分割任务常用 2、4、8
groups分组卷积，减少参数depthwise 时 groups = 通道数
Python · 尺寸与参数量核算
import torch
import torch.nn as nn

conv = nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, padding=1, stride=1)
x = torch.randn(8, 3, 224, 224)
print(conv(x).shape)                      # (8, 64, 224, 224)

# 参数量 = (Cin * K * K + 1) * Cout
params = sum(p.numel() for p in conv.parameters())
print("params:", params)                  # (3*3*3+1)*64 = 1792

# 深度可分离卷积：逐通道卷积 + 1x1 逐点卷积
dw = nn.Conv2d(64, 64, 3, padding=1, groups=64)
pw = nn.Conv2d(64, 128, 1)
print("dw+pw params:", sum(p.numel() for p in dw.parameters())
      + sum(p.numel() for p in pw.parameters()))   # 640 + 8320

# 输出尺寸公式验证：H_out = floor((H + 2P - D(K-1) - 1)/S) + 1
def out_size(h, k, p=0, s=1, d=1):
    return (h + 2 * p - d * (k - 1) - 1) // s + 1

print(out_size(224, 7, 3, 2))              # 112
print(out_size(224, 3, 1, 1, 2))          # 224（膨胀保持尺寸）

5.3 感受野：一个神经元能看多远

感受野是输出特征图上一个点对应原图的区域大小。堆叠小卷积核比一个大卷积核更划算： 两层 3×3 的感受野等于一层 5×5，但参数更少且多了一次非线性。

感受野递推
RFl = RFl−1 + (Kl − 1) · Sl−1    Sl = Sl−1 · sl

RF 从 1 开始，S 从 1 开始。步长会“跳着”扩大感受野， 所以深层特征的一个点往往覆盖原图很大区域。

为什么全局平均池化好用

在分类网络末端用 AdaptiveAvgPool2d(1) 把任意尺寸特征图压成每通道一个数， 再接线性分类头。它替代了巨大的全连接层，参数少、抗过拟合、支持任意输入尺寸。

5.4 经典架构的演进

网络年份关键贡献教训
LeNet-51998卷积 + 池化 + 全连接的基本范式结构小而完整，适合入门
AlexNet2012ReLU、Dropout、GPU 训练深度 + 大数据 + 算力三者缺一不可
VGG2014全部使用 3×3 卷积堆叠小核堆叠即可获得大感受野
GoogLeNet2014Inception 多尺度并行、1×1 瓶颈宽度上的多尺度融合
ResNet2015残差连接，训练 100+ 层恒等映射让深层网络可优化
MobileNet2017深度可分离卷积移动端参数与算力约束
EfficientNet2019复合缩放（深度/宽度/分辨率）缩放要按比例协同
ConvNeXt2022借鉴 Transformer 设计现代化 CNN架构边界正在消失
残差块
y = x + F(x; W)    ∂y ∂x = I + ∂F ∂x

恒等路径让梯度有一条“直通车道”，即使 F 的梯度很小，∂y/∂x 仍包含单位矩阵。 这是深层网络可训练的关键。维度不匹配时用 1×1 卷积调整通道。

卷积 vs Transformer

卷积有强归纳偏置（局部性、平移等变），小数据上更占优；Transformer 感受野全局、 可扩展性更好，大数据上更强。现代视觉模型常混合两者（如 ConvNeXt、Swin）。

5.5 代码：为 CIFAR-10 写一个小 ResNet

下面是一个约 1.7M 参数的小型 ResNet，单卡几分钟就能在 CIFAR-10 上跑到 90% 以上。 重点是结构清晰：stem → 三个 stage → 全局池化 → 分类头。

Python · 小型 ResNet
import torch
import torch.nn as nn
import torch.nn.functional as F

class BasicBlock(nn.Module):
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(cin, cout, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(cout)
        self.conv2 = nn.Conv2d(cout, cout, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(cout)
        self.short = nn.Sequential()
        if stride != 1 or cin != cout:
            self.short = nn.Sequential(
                nn.Conv2d(cin, cout, 1, stride, bias=False),
                nn.BatchNorm2d(cout),
            )

    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return F.relu(out + self.short(x))

class SmallResNet(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.stem = nn.Sequential(
            nn.Conv2d(3, 64, 3, 1, 1, bias=False), nn.BatchNorm2d(64), nn.ReLU()
        )
        self.layer1 = nn.Sequential(BasicBlock(64, 64), BasicBlock(64, 64))
        self.layer2 = nn.Sequential(BasicBlock(64, 128, 2), BasicBlock(128, 128))
        self.layer3 = nn.Sequential(BasicBlock(128, 256, 2), BasicBlock(256, 256))
        self.head = nn.Linear(256, num_classes)

    def forward(self, x):
        x = self.stem(x)                   # (B, 64, 32, 32)
        x = self.layer1(x)                 # (B, 64, 32, 32)
        x = self.layer2(x)                 # (B, 128, 16, 16)
        x = self.layer3(x)                 # (B, 256, 8, 8)
        x = F.adaptive_avg_pool2d(x, 1).flatten(1)
        return self.head(x)

model = SmallResNet()
print("params:", sum(p.numel() for p in model.parameters()))   # 约 1.7M
Python · 训练片段（CIFAR-10）
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

tf_train = transforms.Compose([
    transforms.RandomCrop(32, padding=4),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)),
])
tf_test = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)),
])

train_set = datasets.CIFAR10("data", train=True, download=True, transform=tf_train)
test_set = datasets.CIFAR10("data", train=False, download=True, transform=tf_test)
train_loader = DataLoader(train_set, batch_size=128, shuffle=True, num_workers=4)
test_loader = DataLoader(test_set, batch_size=256, num_workers=4)

device = "cuda" if torch.cuda.is_available() else "cpu"
model = SmallResNet().to(device)
opt = torch.optim.SGD(model.parameters(), lr=0.1, momentum=0.9, weight_decay=5e-4)
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=30)

for epoch in range(30):
    model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()
        loss = F.cross_entropy(model(x), y)
        loss.backward()
        opt.step()
    sched.step()
    model.eval()
    correct = 0
    with torch.no_grad():
        for x, y in test_loader:
            correct += (model(x.to(device)).argmax(1) == y.to(device)).sum().item()
    print(epoch, "acc:", correct / len(test_set))

上面的均值方差是 CIFAR-10 的统计值。换数据集必须重新计算，否则输入分布偏移会显著掉点。

5.6 本章小结

卷积网络的核心

  • 局部连接 + 权重共享 + 平移等变，让参数量与图像尺寸解耦。
  • 输出尺寸用公式核算，或用“能滑几步”的心算方法。
  • 小核堆叠优于大核：参数更少、非线性更多、感受野相同。
  • 残差连接给梯度提供直通路径，是深层网络可训练的基础。
  • 1×1 卷积用于通道升降维与跨通道信息融合。
  • 深度可分离卷积把标准卷积拆成空间与通道两步，大幅降参数量。

常见误区

  1. 卷积层后忘记加激活函数，堆叠退化为线性变换。
  2. padding 与 stride 搭配错误，特征图尺寸出现小数或意外缩小。
  3. 残差分支与主分支通道数不一致，直接相加报错。
  4. BN 放在激活之前还是之后，不同架构约定不同，改动前先看原论文。
