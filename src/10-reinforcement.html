第三部分 · 生成与决策

强化学习：在试错中学习决策

监督学习告诉你“正确答案是什么”，强化学习只给一个延迟的分数。 智能体必须在探索与利用之间权衡，从稀疏奖励中推断“哪一步做对了”。 它也是大模型对齐（RLHF）的理论基础。

预计 65 分钟前置：第 1、3 章 关键词：MDP · Bellman · 策略梯度 · PPO

10.1 马尔可夫决策过程

强化学习把问题形式化为 MDP：状态、动作、转移、奖励、折扣因子。 “马尔可夫”意味着未来只依赖当前状态，与更早的历史无关。

要素符号含义
状态s ∈ S智能体观察到的环境信息
动作a ∈ A可选行为
转移P(s′|s,a)执行动作后的状态分布
奖励r(s,a)即时反馈，可能稀疏、延迟
折扣γ ∈ [0,1)未来奖励的折现率，控制视野
回报与状态价值
Gt = Σk≥0 γkrt+k+1    Vπ(s) = Eπ[Gt|st=s]

γ 越接近 0 越短视，越接近 1 越重视长期收益。 价值函数回答“在状态 s、按策略 π 行动，期望能拿多少分”。

动作价值与 Bellman 期望方程
Qπ(s,a) = r(s,a) + γ Es′[Vπ(s′)]
Vπ(s) = Σa π(a|s)Qπ(s,a)

Bellman 方程把“长期价值”拆成“即时奖励 + 下一状态价值”。 所有值迭代、策略迭代、TD 学习都从这个递归出发。

10.2 基于价值：Q-Learning 与 DQN

如果能准确估计每个动作的 Q 值，策略就是“选 Q 最大的动作”。Q-Learning 用 TD 误差 在线更新，深度版本 DQN 用网络拟合 Q 函数，并用经验回放与目标网络稳定训练。

Q-Learning 更新（off-policy）
Q(s,a) ← Q(s,a) + α[ r + γ maxa′Q(s′,a′) − Q(s,a)]

max 操作让目标策略与行为策略分离，因此可以用旧数据学习（off-policy）。 经验回放打散时间相关性，目标网络冻结一段时间，避免“自己追自己”导致发散。

DQN 损失
L = E[(r + γ maxa′Qθ−(s′,a′) − Qθ(s,a))2]

θ− 是目标网络参数，定期从 θ 同步。Double DQN 用在线网络选动作、 目标网络估值，缓解 Q 值高估。

10.3 策略梯度：直接优化策略

价值方法只能处理离散动作，且难以表达随机策略。策略梯度直接参数化 πθ(a|s)，用“让高回报动作概率变大”的直觉优化期望回报。

策略梯度定理
∇θJ(θ) = Eπ[∇θlog πθ(a|s) · Gt]

对数概率的梯度方向是“让这个动作更可能发生”，乘以回报作为权重。 回报高则强化，回报低则抑制。REINFORCE 用整条轨迹的回报估计，方差很大。

引入基线降低方差
∇θJ(θ) = E[∇θlog πθ(a|s) · (Gt − b(s))]

减去与动作无关的基线不改变期望，但显著降低方差。 常用基线是状态价值 V(s)，差值就是优势函数 A = Q − V。

优势函数与 GAE
Aπ(s,a) = Qπ(s,a) − Vπ(s)

优势回答“这个动作比平均水平好多少”。 GAE 用 TD 残差的指数加权和，在偏差与方差之间做权衡，是 PPO 的标准配置。

10.4 Actor-Critic 与 PPO

Actor 负责选动作，Critic 负责评估状态价值。PPO 在策略梯度的基础上加了一个“信任域”约束： 每次更新不能让新策略离旧策略太远，否则性能会崩塌。

重要性采样比率
rt(θ) = πθ(at|st) πθold(at|st)

比率大于 1 表示新策略更倾向该动作。 用旧策略采样的数据可以多次更新，提高样本效率。

PPO 裁剪目标
LCLIP = Et[min(rtAt, clip(rt, 1−ε, 1+ε)At)]

ε 通常取 0.2。比率超出范围后梯度被截断，避免一次更新把策略带偏。 总损失还包含价值损失与熵奖励（鼓励探索）。

算法类型动作空间样本效率稳定性
Q-Learning / DQN值方法离散高（可回放）需目标网络
REINFORCE策略梯度离散/连续低方差大
A2C / A3CActor-Critic两者皆可中中等
PPOActor-Critic两者皆可中高好，工业默认

与 RLHF 的关系

大模型对齐把“生成回答”看作动作，把奖励模型打分看作奖励，用 PPO 优化策略。 区别在于动作空间是词表，状态是提示词 + 已生成前缀。第 12 章会展开这条链路。

10.5 代码：REINFORCE 与 PPO 损失

Python · REINFORCE（带基线）
import torch
import torch.nn as nn

class Policy(nn.Module):
    def __init__(self, obs_dim=4, n_actions=2, hidden=64):
        super().__init__()
        self.body = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.Tanh(),
            nn.Linear(hidden, hidden), nn.Tanh(),
        )
        self.logits = nn.Linear(hidden, n_actions)
        self.value = nn.Linear(hidden, 1)

    def forward(self, obs):
        h = self.body(obs)
        return self.logits(h), self.value(h).squeeze(-1)

def compute_returns(rewards, gamma=0.99):
    out, running = [], 0.0
    for r in reversed(rewards):
        running = r + gamma * running
        out.append(running)
    return torch.tensor(list(reversed(out)), dtype=torch.float32)

def reinforce_step(policy, opt, obs, actions, rewards):
    logits, values = policy(obs)
    dist = torch.distributions.Categorical(logits=logits)
    logp = dist.log_prob(actions)
    returns = compute_returns(rewards)
    adv = returns - values.detach()                # 用 V(s) 作基线
    policy_loss = -(logp * adv).mean()
    value_loss = nn.functional.mse_loss(values, returns)
    loss = policy_loss + 0.5 * value_loss
    opt.zero_grad()
    loss.backward()
    opt.step()
    return loss.item()
Python · PPO 裁剪损失
import torch
import torch.nn.functional as F

def ppo_loss(new_logits, old_logits, actions, advantages, clip=0.2):
    new_logp = F.log_softmax(new_logits, dim=-1).gather(1, actions.view(-1, 1)).squeeze(1)
    old_logp = F.log_softmax(old_logits, dim=-1).gather(1, actions.view(-1, 1)).squeeze(1)
    ratio = (new_logp - old_logp).exp()            # π_new / π_old
    unclipped = ratio * advantages
    clipped = torch.clamp(ratio, 1 - clip, 1 + clip) * advantages
    return -torch.min(unclipped, clipped).mean()

B, A = 8, 4
new_logits, old_logits = torch.randn(B, A), torch.randn(B, A)
actions = torch.randint(0, A, (B,))
adv = torch.randn(B)
print(ppo_loss(new_logits, old_logits, actions, adv).item())
优势必须 detach

策略损失里，优势与回报只作为“权重”，不能对它们反传。 忘记 .detach() 会让价值网络通过策略损失被二次更新，训练不稳定。

10.6 本章小结

强化学习的四条经验

  • 先明确 MDP：状态、动作、奖励、终止条件，奖励设计决定上限。
  • 值方法适合离散动作与高样本效率场景，策略梯度适合连续动作与随机策略。
  • 基线、GAE、优势归一化都是降低方差的手段。
  • PPO 用裁剪把更新限制在信任域内，是工业界最常用的默认算法。
  • 奖励稀疏时考虑课程学习、内在奖励、示范数据或逆强化学习。
  • 评估要看多随机种子的均值与方差，单条曲线没有意义。

常见误区

  1. 只看平均回报，不看方差与成功率。
  2. 奖励函数设计有漏洞，智能体学会“刷分”而不是完成任务。
  3. 经验回放与目标网络缺失，DQN 训练发散。
  4. 策略损失中对优势反传，导致价值函数被污染。
  5. 探索不足，策略过早收敛到局部最优。
