第二部分 · 核心架构

序列模型：从循环网络到注意力

文本、语音、时间序列都有顺序依赖。RNN 用隐藏状态携带历史信息， 却受限于梯度消失与串行计算；LSTM 用门控缓解前者，Transformer 用注意力解决后者。 这一章是从 RNN 走向大模型的必经路口。

预计 60 分钟前置：第 3、4 章 关键词：BPTT · 门控 · Seq2Seq · Beam Search

6.1 序列任务的四种形态

形态输入 → 输出例子典型结构
一对一固定 → 固定图像分类CNN
多对一序列 → 单个情感分类、故障检测RNN 取最后状态
一对多单个 → 序列图像描述、音乐生成解码器逐步生成
多对多序列 → 序列翻译、摘要、语音识别Encoder–Decoder

深度学习里序列通常表示为 (B, T, D)：batch、时间步、特征维。 注意 PyTorch 的 nn.LSTM 默认要求 (T, B, D)， 除非设置 batch_first=True。形状约定错位是序列代码最常见的 bug。

6.2 循环神经网络与 BPTT

RNN 在每个时间步复用同一组参数，把上一刻的隐藏状态和当前输入一起更新。 这让它能处理任意长度的序列，但训练时必须沿时间展开计算图。

RNN 单元
ht = tanh(Whh ht−1 + Wxh xt + bh)    yt = Why ht + by

同一组 W 在所有时间步共享，因此参数量与序列长度无关。 隐藏状态是“记忆”，但它容量固定，长序列会遗忘早期信息。

沿时间反向传播（BPTT）的梯度
∂L ∂h1 = Σt ∂Lt ∂ht ∏k=2..t ∂hk ∂hk−1

每个因子都含 WhhT 与 tanh′。 连乘导致梯度指数衰减或爆炸，长依赖学不到。工程上用梯度裁剪 + 门控结构缓解。

截断 BPTT

超长序列无法一次展开，常用截断反向传播：只回传最近 k 步，隐藏状态跨 chunk 传递但不回传梯度。 这会牺牲极长依赖，但让训练可行。

6.3 LSTM：用门控控制记忆

LSTM 引入细胞状态 ct 与三个门：遗忘门决定丢弃多少旧信息， 输入门决定写入多少新信息，输出门决定暴露多少给隐藏状态。细胞状态的更新以加法为主， 梯度可以沿“传送带”较稳定地流动。

LSTM 门控方程
ft = σ(Wf[ ht−1, xt] + bf)    it = σ(Wi[ ht−1, xt] + bi)
ct = ft ⊙ ct−1 + it ⊙ tanh(Wc[ht−1, xt] + bc)
ot = σ(Wo[ ht−1, xt] + bo)    ht = ot ⊙ tanh(ct)

σ 输出 (0,1)，充当“开合程度”。遗忘门接近 1 表示保留，接近 0 表示清空。 细胞状态的加法路径让梯度不必每步都经过矩阵乘法与饱和激活。

GRU：更轻量的门控

GRU 把遗忘门与输入门合并为更新门 z，并引入重置门 r，只有两个门、没有独立细胞状态，参数比 LSTM 少约 25%， 在很多任务上表现相当。

GRU 更新
zt = σ(Wz[ ht−1,xt])    rt = σ(Wr[ ht−1,xt])
h̃t = tanh(W[ rt ⊙ ht−1, xt])    ht = (1−zt)⊙ ht−1 + zt ⊙ h̃t

更新门直接控制“保留旧状态”还是“写入候选状态”， 是 LSTM 遗忘/输入门的简化版。

6.4 Seq2Seq 与解码策略

Encoder 把输入序列压缩成一个上下文向量，Decoder 从这个向量出发逐步生成输出。 中间那个固定长度向量是瓶颈，注意力机制（第 7 章）正是为了解决它。

条件语言模型分解
p(y1..T|x) = ∏t p(yt| y<t, x)

自回归生成：每步把已生成的 token 作为下一步输入。 训练时用 teacher forcing（喂真实前缀），推理时喂模型自己的输出，二者存在分布差异。

解码策略做法优点缺点
贪心每步取最大概率快容易陷入局部最优、重复
Beam Search保留 top-k 条候选路径质量更高计算量 k 倍、可能过于保守
温度采样按 p/T 采样多样性可控T 过高会胡言乱语
Top-k / Top-p截断低概率词后采样质量与多样性平衡需要调参
曝光偏差

训练时模型总看到正确前缀，推理时看到自己的错误输出，误差会逐步累积。 缓解方法：计划采样（逐步混入模型输出）、强化学习微调、或直接用大规模预训练。

6.5 代码：LSTM 文本分类与逐步生成

Python · LSTM 分类器
import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size, emb_dim=128, hidden=256, num_classes=2):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, emb_dim, padding_idx=0)
        self.lstm = nn.LSTM(
            emb_dim, hidden, num_layers=2, batch_first=True,
            bidirectional=True, dropout=0.2
        )
        self.head = nn.Linear(hidden * 2, num_classes)

    def forward(self, ids, lengths):
        # ids: (B, T)  lengths: (B,) 真实长度，用于忽略 padding
        emb = self.embed(ids)                         # (B, T, D)
        packed = nn.utils.rnn.pack_padded_sequence(
            emb, lengths.cpu(), batch_first=True, enforce_sorted=False
        )
        out, (h, c) = self.lstm(packed)
        out, _ = nn.utils.rnn.pad_packed_sequence(out, batch_first=True)
        # 取每个样本最后一个有效时间步
        idx = (lengths - 1).view(-1, 1, 1).expand(-1, 1, out.size(2))
        last = out.gather(1, idx).squeeze(1)          # (B, 2H)
        return self.head(last)

model = LSTMClassifier(vocab_size=10000)
ids = torch.randint(1, 10000, (16, 40))
lengths = torch.randint(10, 41, (16,))
logits = model(ids, lengths)
print(logits.shape)                                    # (16, 2)
必须 pack

padding 位置若参与 LSTM 计算，最后状态会被补零污染。使用 pack_padded_sequence 才能真正跳过 padding，并保证长度排序正确。

Python · 手写 RNN 单元（理解状态更新）
import torch
import torch.nn as nn

class ManualRNN(nn.Module):
    def __init__(self, input_dim, hidden_dim):
        super().__init__()
        self.wx = nn.Linear(input_dim, hidden_dim, bias=False)
        self.wh = nn.Linear(hidden_dim, hidden_dim, bias=True)

    def forward(self, x, h=None):
        # x: (B, T, D)
        B, T, _ = x.shape
        if h is None:
            h = torch.zeros(B, self.wh.out_features, device=x.device)
        outs = []
        for t in range(T):
            h = torch.tanh(self.wx(x[:, t]) + self.wh(h))
            outs.append(h)
        return torch.stack(outs, dim=1), h

cell = ManualRNN(32, 64)
x = torch.randn(4, 12, 32)
out, h = cell(x)
print(out.shape, h.shape)          # (4, 12, 64) (4, 64)
实践建议

今天的序列建模优先考虑 Transformer（第 7 章）。RNN 仍有价值： 流式/低延迟场景、超长序列的线性复杂度变体（如 S4、Mamba），以及理解序列建模的基础概念。

6.6 本章小结

序列建模的关键

  • 序列张量约定要统一：batch_first 与 (T, B, D) 不能混用。
  • BPTT 是沿时间展开的链式法则，长依赖会梯度消失。
  • LSTM 靠细胞状态的加法路径与门控缓解梯度问题。
  • Seq2Seq 的固定上下文向量是瓶颈，注意力是解决方案。
  • 训练用 teacher forcing，推理用自回归，存在曝光偏差。
  • 解码策略决定生成质量与多样性，Beam 与采样各有用武之地。

常见误区

  1. 忘记 batch_first=True，把 batch 与时间步颠倒。
  2. padding 不打包，最后状态被补零稀释。
  3. 初始隐藏状态没有放到正确 device 上。
  4. 长序列不做梯度裁剪，训练几步后 loss 变 NaN。
  5. 用贪心解码评估翻译质量，低估模型真实能力。
