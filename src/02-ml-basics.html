第一部分 · 基础

机器学习基础：从任务定义到可信评估

在写第一行神经网络代码之前，先回答三个问题：要预测什么、用什么损失衡量、 怎样验证模型真的有用。这一章建立完整的建模流程，后续所有模型都只是这条流程里可替换的一环。

预计 55 分钟前置：第 1 章 关键词：经验风险 · 偏差方差 · 交叉验证

2.1 四种学习范式

机器学习按“监督信号从哪来”分为四类。深度学习的成功，很大程度来自它能在前三类任务上 用同一套梯度下降框架训练。

范式数据形态典型任务代表模型
监督学习(x, y) 成对标注分类、回归、检测、分割ResNet、BERT
无监督学习只有 x聚类、降维、密度估计K-Means、PCA、VAE
自监督学习从 x 自动构造标签语言建模、对比学习、掩码重建GPT、SimCLR、MAE
强化学习与环境交互得到奖励控制、游戏、对齐DQN、PPO

实际系统常常混用：先自监督预训练，再监督微调，最后用强化学习对齐偏好。 不要把范式当标签，而要把它当“标签从哪来”的问题。

2.2 学习就是最小化经验风险

真实分布 P(X, Y) 未知， 我们只有训练集。于是用训练集上的平均损失（经验风险）替代真实风险，再用优化算法求解。

经验风险最小化
Remp(θ) = 1N Σi=1N ℓ(fθ(xi), yi) + λΩ(θ)

第一项要求拟合数据，第二项（正则）限制模型复杂度。 两者平衡决定了泛化能力，这就是“欠拟合 / 过拟合”的来源。

损失函数怎么选

损失必须与任务和输出层的概率假设匹配。用错损失，模型可能仍会下降，但优化目标已经偏了。

任务输出层损失说明
回归线性（1 维）MSE / MAE / HuberMSE 对大误差敏感，MAE 更鲁棒
二分类Sigmoid（1 维）BCE输出为概率，需 log 稳定实现
多分类Softmax（C 维）交叉熵配合 logits，不要先手动 softmax
多标签C 个独立 Sigmoid逐标签 BCE 求和标签不互斥时不能用 softmax
排序 / 检索相似度分数Triplet / InfoNCE关注正负样本相对关系
均方误差与二元交叉熵
MSE = 1N Σi(ŷi − yi)2    BCE = −1N Σi[yi log ŷi + (1 − yi) log(1 − ŷi)]

MSE 对应高斯噪声假设，BCE 对应伯努利分布。 分类任务请直接把 logits 传给 cross_entropy，它内部融合了 log-softmax， 比“先 softmax 再取 log”数值稳定得多。

2.3 从线性模型理解训练循环

线性回归与逻辑回归是最小的完整闭环：模型 → 损失 → 梯度 → 更新。 把它们跑通一遍，你之后看到的任何网络都只是把“模型”换成更深的函数。

线性模型与逻辑回归
ŷ = wTx + b    p(y=1|x) = σ(wTx + b)    σ(z) = 1 1 + e−z

线性回归的梯度是 XT(ŷ − y)/N； 逻辑回归 + BCE 的梯度形式完全一样，只是 ŷ 多过了一层 sigmoid。

Python · 线性回归与逻辑回归
import torch
import torch.nn as nn

torch.manual_seed(0)

# ---- 线性回归：y = 3x + 2 + 噪声 ----
X = torch.randn(200, 1)
y = 3 * X + 2 + 0.3 * torch.randn(200, 1)
model = nn.Linear(1, 1)
opt = torch.optim.SGD(model.parameters(), lr=0.1)

for step in range(100):
    pred = model(X)
    loss = nn.functional.mse_loss(pred, y)
    opt.zero_grad()
    loss.backward()
    opt.step()
print("w,b =", model.weight.item(), model.bias.item())   # 接近 3 和 2

# ---- 逻辑回归：二维二分类 ----
N = 400
X = torch.randn(N, 2)
true_w = torch.tensor([2.0, -1.0])
y = ((X @ true_w + 0.5) > 0).float().view(-1, 1)

clf = nn.Linear(2, 1)
opt = torch.optim.SGD(clf.parameters(), lr=0.5)
for step in range(200):
    logits = clf(X)
    loss = nn.functional.binary_cross_entropy_with_logits(logits, y)
    opt.zero_grad()
    loss.backward()
    opt.step()

with torch.no_grad():
    acc = (((clf(X) > 0).float()) == y).float().mean()
print("accuracy:", acc.item())
训练循环的五个固定动作

前向计算 → 计算损失 → zero_grad() → backward() → step()。顺序错了就会出现梯度累积或更新失效。第 4 章会把每个动作展开。

2.4 数据划分与交叉验证

模型在训练集上的表现没有意义，我们需要估计它在未见数据上的表现。标准做法是三层划分： 训练集用于更新参数，验证集用于选择超参数与早停， 测试集只在最后用一次。

方式适用场景注意点
留出法（70/15/15）数据量大划分要分层，保证类别比例
K 折交叉验证数据较少K=5 或 10，训练 K 次成本较高
时间序列切分时序预测不能随机打乱，只能用过去预测未来
分组划分同一用户/患者多条记录同一组不能跨训练与验证
数据泄漏

先在全量数据上做标准化、选特征、过采样，再划分数据集，会让验证集信息泄漏到训练中， 指标虚高。所有拟合型预处理只能在训练集上 fit，再 transform 验证集。

2.5 评估指标：别只看准确率

类别不平衡时准确率会骗人：99 个负样本 1 个正样本，全预测为负就有 99% 准确率。 此时要看去向分类矩阵（TP / FP / FN / TN）派生的指标。

精确率、召回率与 F1
P = TP TP + FP    R = TP TP + FN    F1 = 2PR P + R

精确率回答“报警的里面有多少是真的”，召回率回答“真的里面抓到了多少”。 两者通常互相牺牲，阈值就是调节旋钮。

ROC-AUC 的直觉
AUC = P(s正 > s负)

随机抽一个正样本和一个负样本，模型给正样本打分更高的概率。 与阈值无关，适合比较模型排序能力；极度不平衡时 PR-AUC 更敏感。

任务主指标辅助指标
分类（均衡）AccuracyF1、AUC
分类（不平衡）F1 / PR-AUCRecall@固定精确率
回归RMSE / MAER²、分位数误差
检测mAP@0.5:0.95每类 AP、小目标 AP
分割mIoU / Dice边界 F1
生成FID / CLIPScore人工评测、多样性

2.6 偏差—方差：模型为什么不泛化

泛化误差可以分解为偏差、方差与不可约噪声。偏差是模型假设太简单带来的系统性错误， 方差是对训练数据扰动过于敏感带来的波动。

偏差—方差分解（平方损失）
E[(y − f(x))2] = Bias2 + Var + σ2

Bias = (E[f] − 真实函数)²，Var = E[(f − E[f])²]。 模型容量增加通常降低偏差、提高方差；数据量增加主要降低方差。

症状训练误差验证误差对策
欠拟合（高偏差）高高更大模型、更多特征、减小正则、训练更久
过拟合（高方差）低高更多数据、数据增强、正则、早停、简化模型
训练/验证都低低低正常，继续提升数据难度或换指标
训练低 / 验证极高低极高检查数据泄漏与分布偏移
深度学习的“双下降”现象

经典偏差—方差理论预测参数多于样本后必然过拟合，但现代网络在“插值阈值”之后 测试误差反而再次下降。这提醒我们：理论是地图，不是领土， 仍要以实验为准。

2.7 正则化与模型选择

正则化的本质是给假设空间加约束，让模型偏向“简单”的解。常见手段有：

  • L2 正则（weight decay）：在损失中加 λ‖w‖²，抑制大权重。
  • L1 正则：加 λ‖w‖₁，产生稀疏权重，可做特征选择。
  • 早停：验证损失开始上升就停止，等价于限制参数的有效搜索范围。
  • 数据增强：翻转、裁剪、颜色扰动、Mixup，最有效的“免费数据”。
  • Dropout：训练时随机置零激活，迫使表示冗余（详见第 4 章）。
L2 正则的贝叶斯解释
θMAP = argmaxθ [log p(D|θ) + log p(θ)],    p(θ) = N(0, σ2I)

高斯先验对应 L2，拉普拉斯先验对应 L1。正则项不是“技巧”， 而是把先验知识写进目标函数。

2.8 代码：一个可信的评估流程

下面这段代码演示分层划分、训练集内标准化、指标计算。注意 fit 只在训练集上调用。

Python · 评估流程
import numpy as np
import torch
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report, roc_auc_score

X, y = make_classification(
    n_samples=2000, n_features=20, n_informative=8,
    weights=[0.9, 0.1], random_state=42
)
X_tr, X_tmp, y_tr, y_tmp = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42
)
X_val, X_te, y_val, y_te = train_test_split(
    X_tmp, y_tmp, test_size=0.5, stratify=y_tmp, random_state=42
)

scaler = StandardScaler().fit(X_tr)              # 只在训练集 fit
X_tr, X_val, X_te = [torch.tensor(scaler.transform(a), dtype=torch.float32)
                     for a in (X_tr, X_val, X_te)]
y_tr, y_val, y_te = [torch.tensor(b, dtype=torch.float32).view(-1, 1)
                     for b in (y_tr, y_val, y_te)]

model = torch.nn.Linear(X_tr.shape[1], 1)
opt = torch.optim.AdamW(model.parameters(), lr=1e-2, weight_decay=1e-4)
loss_fn = torch.nn.BCEWithLogitsLoss()

best, best_state = 1e9, None
for epoch in range(200):
    model.train()
    opt.zero_grad()
    loss = loss_fn(model(X_tr), y_tr)
    loss.backward()
    opt.step()

    model.eval()
    with torch.no_grad():
        val_loss = loss_fn(model(X_val), y_val).item()   # 早停看验证集
    if val_loss < best:
        best, best_state = val_loss, {k: v.clone() for k, v in model.state_dict().items()}

model.load_state_dict(best_state)
model.eval()
with torch.no_grad():
    prob = torch.sigmoid(model(X_te)).numpy().ravel()
print(classification_report(y_te.numpy().ravel(), prob > 0.5, digits=3))
print("AUC:", roc_auc_score(y_te.numpy().ravel(), prob))
测试集只碰一次

如果反复用测试集调超参数，它实际上变成了验证集，最终指标会乐观偏移。 正确做法是把测试集封存到项目结束前。

2.9 本章小结

建模流程的七个节点

  • 定义任务与输出形式，选匹配的损失函数。
  • 划分训练/验证/测试，守住时间与分组边界。
  • 只在训练集上 fit 预处理，防止数据泄漏。
  • 训练看损失曲线，选择看验证指标，汇报看测试指标。
  • 类别不平衡时用 F1 / PR-AUC，而不是准确率。
  • 用偏差—方差诊断欠拟合与过拟合，再决定加容量还是加正则。
  • 记录随机种子、数据版本、超参数，否则结果不可复现。

常见误区

  1. 用训练集准确率作为最终结论。
  2. 先标准化全量数据再划分，造成泄漏。
  3. 多标签任务错误使用 softmax。
  4. 把 AUC 当成“准确率”，忽略阈值选择。
  5. 只报告一个数字，不提供置信区间或多次运行结果。
