图神经网络：在关系结构上做推理

11.1 图的表示与任务

图由节点集合 V、边集合 E 与节点特征 X ∈ RN×F 组成。邻接矩阵 A ∈ {0,1}N×N 描述连接关系，度矩阵 D 的对角线是每个节点的邻居数。

任务层级预测目标例子输出头
节点级每个节点的标签用户分类、论文主题节点表示 → 线性层
边级边是否存在 / 类型推荐、知识图谱补全两端表示做内积或拼接
图层级整张图的标签分子性质、图分类Readout 聚合后接分类头
为什么不能直接用 MLP

MLP 把每个节点当独立样本，完全忽略连接关系；CNN 要求规则网格；RNN 要求序列顺序。 图的结构不规则、邻居数量可变，需要一种对邻居排列不变的聚合方式。

11.2 消息传递：GNN 的统一框架

每一层做三件事：从邻居收集消息、聚合消息、与自身表示融合更新。 聚合函数必须对邻居顺序不敏感（sum / mean / max）。

消息传递通用形式
mv(l) = AGGu∈N(v) M(l)(hv(l), hu(l), euv)
hv(l+1) = U(l)(hv(l), mv(l))

M 是消息函数，AGG 是排列不变的聚合，U 是更新函数。 GCN、GraphSAGE、GAT、GIN 都可以写进这个框架，区别只在三者如何定义。

层数与感受野
L 层 GNN 的节点表示汇聚了 L 跳邻居

层数太少看不到远距离依赖，层数太多所有节点表示趋同（过平滑）。 实践中 2~4 层往往最优，需要更远的信息时用虚拟节点、残差或图重连。

11.3 GCN：带归一化的邻居平均

GCN 可以看作图上的低通滤波：每个节点的新表示是“自身 + 邻居”的加权平均， 权重由度的乘积归一化，防止高度节点主导。

GCN 层
H(l+1) = σ( D̃−1/2Ã D̃−1/2H(l) W(l))

Ã = A + I 加入自环，D̃ 是 Ã 的度矩阵。 归一化项 1/√(didj) 让高度节点的边权重变小，训练更稳定。

Python · 手写 GCN 层
import torch
import torch.nn as nn
import torch.nn.functional as F

class GCNLayer(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.weight = nn.Linear(in_dim, out_dim, bias=False)
        self.bias = nn.Parameter(torch.zeros(out_dim))

    def forward(self, x, adj):
        # adj: (N, N) 原始邻接矩阵（含自环更佳）
        n = adj.size(0)
        a = adj + torch.eye(n, device=adj.device)      # 加自环
        deg = a.sum(dim=1).pow(-0.5)
        norm = deg.view(-1, 1) * a * deg.view(1, -1)   # D^-1/2 A D^-1/2
        return F.relu(norm @ self.weight(x) + self.bias)

class GCN(nn.Module):
    def __init__(self, in_dim, hidden, num_classes, dropout=0.5):
        super().__init__()
        self.g1 = GCNLayer(in_dim, hidden)
        self.g2 = GCNLayer(hidden, num_classes)
        self.drop = nn.Dropout(dropout)

    def forward(self, x, adj):
        x = self.drop(F.relu(self.g1(x, adj)))
        return self.g2(x, adj)

x = torch.randn(10, 16)
adj = (torch.rand(10, 10) > 0.5).float()
adj = ((adj + adj.t()) > 0).float()                   # 对称化
model = GCN(16, 32, 3)
print(model(x, adj).shape)                              # (10, 3)

11.4 GraphSAGE 与 GAT

GCN 需要整张图的邻接矩阵，难以做大规模归纳学习。GraphSAGE 采样固定数量的邻居， 聚合后与自身拼接，可对 unseen 节点直接推理。GAT 则用注意力给邻居分配不同权重。

GraphSAGE 聚合
hN(v) = AGG({hu, u ∈ N(v)})    hv′ = σ(W · [hv ‖ hN(v)])

聚合函数可选 mean / LSTM / max-pool。拼接而非相加保留了“自身”与“邻居”的区分。

GAT 的注意力系数
αvu = softmaxu∈N(v)( LeakyReLU(aT[Whv ‖ Whu]))
hv′ = σ(Σu∈N(v) αvuWhu)

多头 GAT 与 Transformer 的多头注意力思路一致。 注意力让模型自动识别“哪些邻居更重要”，可解释性也更好。

模型聚合方式是否用边权适合
GCN度归一化加权平均可扩展转导式节点分类
GraphSAGE采样 + 拼接聚合否大规模归纳学习
GAT多头注意力可扩展异质邻居重要性差异大
GINsum + MLP否图分类，表达力强

11.5 过平滑、过挤压与读出

过平滑

层数增加后，邻居聚合反复平均，所有节点表示趋于同一向量，分类能力下降。 表现是训练/验证准确率随层数增加先升后降。对策：残差连接、Jumping Knowledge、 PairNorm、限制层数。

过挤压

图分类任务中，节点数远大于隐藏维度时，把大量信息压进固定向量会丢失细节。 对策：更宽的表示、层级池化（DiffPool）、或使用能保留结构的读出。

图级读出
hG = READOUT({hv(L), v ∈ V})    ŷ = MLP(hG)

READOUT 常用 sum / mean / max 或注意力加权。 对分子性质预测，sum 通常比 mean 更合适，因为它保留规模信息。

11.6 本章小结

GNN 的关键结论

  • 图学习的核心是排列不变的邻居聚合。
  • GCN 用归一化邻接矩阵做加权平均，是最常用的基线。
  • GraphSAGE 通过邻居采样支持大规模与归纳学习。
  • GAT 用注意力区分邻居重要性，适合异质图。
  • 层数不是越多越好，过平滑会抹平节点差异。
  • 图分类需要读出层，聚合方式要与任务语义匹配。

常见误区

  1. 邻接矩阵没有对称化或忘记加自环。
  2. 在节点分类中随机划分节点，导致邻居信息泄漏到验证集。
  3. 盲目堆叠 10 层 GCN，性能因过平滑反而下降。
  4. 度归一化实现错误，维度广播方向搞反。
  5. 图分类用 mean 读出，丢失了节点数量这一重要特征。
