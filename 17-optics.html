光学中的深度学习：从相位恢复到光子计算

光学里充满病态逆问题——相位、衍射、散射让"观测到光场"到"还原物体"远非一步到位。 深度学习把物理先验编码进网络结构，让 U-Net、无训练网络、物理展开网络成为计算成像的标配。 本章从逆问题讲起，深入 U-Net 架构，覆盖相位恢复、超表面逆向设计、光子神经网络， 并附上可运行的相位恢复 U-Net 代码与本人复现项目。

17.1 为什么光学需要深度学习

光学测量的本质是逆问题：我们能拿到的是探测器上的强度分布 （像素值），想还原的是物体本身的振幅、相位、折射率等物理量。这个映射通常 病态（ill-posed）且非线性——丢失的相位、卷积模糊、噪声都会让 解不唯一。传统方法依赖物理模型 + 迭代优化，慢且对噪声敏感。

光学任务观测想还原难点
相位恢复远场强度 |F(u)|²复数场 u相位丢失
全息重建干涉强度复数振幅孪生像、噪声
去卷积 / 超分辨模糊图像清晰图像核未知、病态
超表面设计目标光学响应结构参数逆向非凸
散射成像散斑物体记忆效应有限

深度学习在这里的角色有三：① 学习正演模型（用网络逼近物理前向， 加速仿真）；② 直接学逆映射（观测 → 物体，端到端）； ③ 展开迭代（把传统优化算法展开成网络，兼具物理可解释性与数据驱动）。

先懂物理，再上网络

光学 DL 不是把 CNN 往数据上一扔。理解前向模型（衍射积分、传输矩阵）、 噪声来源、采样约束，才能设计正确的网络输入输出、损失函数与物理一致性约束。 不懂物理的 DL 光学，常常"看起来对"但物理上站不住。

17.2 光学逆问题的数学结构

前向模型与逆问题
y = A(x) + n,    求 x

x 是物体（振幅/相位/结构），A 是前向算子（衍射、卷积、散射矩阵）， y 是观测强度，n 是噪声。逆问题的病态体现在 A 不是满秩或条件数极大。

正则化化解
x̂ = argminx ‖y − A(x)‖² + λ R(x)

R(x) 是正则项（TV、稀疏、低秩），λ 权衡数据保真与先验。 深度学习的核心贡献之一就是用数据驱动的方式学到 R(x)，甚至学到整个逆映射。

经典方法：Gerchberg–Saxton 迭代

相位恢复的标杆算法。在物面与像面之间交替传播，分别施加振幅约束。 本质是投影到两个凸集的交，但这两个集非凸，因此容易陷入局部解。

GS 单次迭代
uk+1 = A−1{ I · exp( i∠A(uk)) }

A 是傅里叶/衍射算子，I 是测得的强度，∠ 取相位。 每轮保留测量面的振幅、替换相位，再反传回去。

GS 的局限

收敛慢、对初值敏感、易陷入局部极小。改进路线：① 过采样提高唯一性； ② 混合输入-输出（HIO）放松约束；③ 用深度网络做初值或直接替代迭代。

17.3 CNN 在光学成像中的应用

光学图像天然具有局部性与平移不变性——这正是卷积的归纳偏置。 一个 3×3 卷积核可以理解为"局部衍射/散射响应"，多层堆叠逐步扩大感受野， 从强度图中恢复相位或高频细节。

图像重建

输入低质观测（模糊、噪声、欠采样），输出清晰图像。 代表：DnCNN 去噪、RCAN 超分辨、NAFNet 去模糊。

相位恢复

输入强度（或衍射图），输出相位/复数场。 代表：PR-DAD、Res-U2Net、DeepMMSE。

全息重建

输入全息图，输出振幅+相位。代表：eHolo、Y-Net、物理感知风格迁移。

散射透过

输入散斑，输出原图。代表：基于 U-Net 的散射介质成像。

纯 CNN 端到端方法的优势是快（一次前向即出结果）、可针对特定数据分布优化； 缺点是物理一致性难保证——网络可能"猜"出与物理不符的解。 因此更可靠的做法是把物理模型嵌进网络（见 17.6 节）。

17.4 U-Net 架构深度解析

U-Net 是光学成像领域最成功的网络结构，没有之一。它的编码器-解码器 + 跳跃连接 设计完美匹配"从局部观测恢复全局结构"的任务。

整体结构

  1. 编码器（左半）：逐级下采样，用卷积+ReLU 提取特征， 每级感受野翻倍，通道数翻倍。高层特征语义强但空间分辨率低。
  2. 瓶颈层：最深层，感受野最大，负责全局上下文。
  3. 解码器（右半）：逐级上采样，恢复空间分辨率。 上采样可用转置卷积或上采样+卷积。
  4. 跳跃连接：编码器同级特征直接拼到解码器， 把高层语义与低层细节结合——这是 U-Net 的灵魂。
跳跃连接的张量拼接
Dl = Conv([ Upsample(Dl+1), El ])

[ , ] 表示沿通道维拼接。El 是编码器第 l 层输出， Dl+1 是解码器上一层上采样后的特征。 拼接后通道数 = 上采样通道 + 编码器通道，再用卷积融合。

上采样：转置卷积 vs 双线性
y2i,2j = Σm,n wm,n · xi+m,j+n

转置卷积可学习上采样权重，但容易产生棋盘伪影； 双线性上采样固定、无伪影但表达力弱。现代 U-Net 常用"上采样+卷积"组合。

为什么 U-Net 适合光学成像

1

多尺度特征

衍射/散射在不同尺度都有结构。编码器捕获全局低频（相位趋势）， 跳跃连接保留局部高频（边缘细节）。

2

端到端可逆

输入输出同尺寸像素级对应，天然适合"强度图 → 相位图"的密集预测。

3

小数据友好

跳跃连接让梯度直达浅层，在光学数据稀缺（几百张）时仍能训练。

U-Net 演进

变体改进适用
Attention U-Net跳跃连接加注意力门，抑制无关区域医学/复杂场景
U²-Net残差 U 块嵌套，更深更宽的多尺度特征显著目标检测/相位
Res-U²-NetU²-Net + 残差，用于无训练相位恢复相位恢复（无 GT）
nnU-Net自动配置管道，自适应数据集医学分割通用
Swin-UNet编码器换 Swin Transformer大感受野需求
论文参考

U-Net 原始论文：Ronneberger et al., U-Net: Convolutional Networks for Biomedical Image Segmentation, MICCAI 2015 arxiv:1505.04597。 Res-U²-Net 相位恢复：Osorio Quero et al., 2024 arxiv:2404.06657。

17.5 代码：用 U-Net 做相位恢复

下面是一个最小可跑的 U-Net 实现，用于"傅里叶强度 → 相位"的端到端恢复。 训练数据由随机相位经 FFT 生成，损失用 MSE（相位）+ 物理一致性（强度约束）。

python · U-Net 相位恢复 
import torch
from torch import nn


class DoubleConv(nn.Module):
    """(Conv - BN - ReLU) × 2。"""
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.block = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_ch), nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_ch), nn.ReLU(inplace=True),
        )

    def forward(self, x):
        return self.block(x)


class UNet(nn.Module):
    def __init__(self, in_ch=1, out_ch=1, base=32):
        super().__init__()
        self.enc1 = DoubleConv(in_ch, base)
        self.enc2 = DoubleConv(base, base * 2)
        self.enc3 = DoubleConv(base * 2, base * 4)
        self.enc4 = DoubleConv(base * 4, base * 8)
        self.bott = DoubleConv(base * 8, base * 16)

        self.pool = nn.MaxPool2d(2)
        self.up   = nn.Upsample(scale_factor=2, mode="bilinear",
                                align_corners=True)

        self.dec4 = DoubleConv(base * 16 + base * 8, base * 8)
        self.dec3 = DoubleConv(base * 8 + base * 4, base * 4)
        self.dec2 = DoubleConv(base * 4 + base * 2, base * 2)
        self.dec1 = DoubleConv(base * 2 + base, base)
        self.out  = nn.Conv2d(base, out_ch, 1)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))
        b  = self.bott(self.pool(e4))

        d4 = self.dec4(torch.cat([self.up(b),  e4], dim=1))
        d3 = self.dec3(torch.cat([self.up(d4), e3], dim=1))
        d2 = self.dec2(torch.cat([self.up(d3), e2], dim=1))
        d1 = self.dec1(torch.cat([self.up(d2), e1], dim=1))
        return self.out(d1)


def physics_loss(pred_phase, measured_intensity):
    """物理一致性：预测场经 FFT 后强度应匹配观测。"""
    field = torch.exp(1j * pred_phase)
    ft = torch.fft.fft2(field)
    recon_intensity = ft.abs() ** 2
    recon_intensity = recon_intensity / recon_intensity.max()
    measured = measured_intensity / measured_intensity.max()
    return nn.functional.mse_loss(recon_intensity, measured)
训练技巧

光学数据少时，先在仿真数据上预训练，再用少量实测数据微调； 物理一致性损失（physics_loss）能显著降低对真值相位的依赖。 若完全没有真值，可改用无训练网络（见下节）。

17.6 物理启发与无训练网络

光学数据标注极难（真值相位靠干涉才能测），无训练（untrained）方法应运而生： 不依赖任何数据集，只用物理模型 + 网络结构先验就能解逆问题。

Deep Image Prior

随机初始化的网络本身就自带"自然图像"的低维结构先验。固定一张观测图， 反复让网络拟合它，早期停止即可恢复干净图像——不需要任何训练数据。

DIP 目标
minθ ‖ A(fθ( z)) − y ‖²

z 是固定随机输入，fθ 是随机初始化网络，A 是前向算子。 优化 θ 使网络输出经 A 后匹配观测 y。网络倾向先拟合信号后拟合噪声， 因此早期停止能去噪、去伪影。

深度展开（Deep Unfolding）

把传统迭代算法（如 GS、ADMM）的每一步展开成网络层，每步含可学习参数。 既保留物理可解释性，又有数据驱动的收敛加速。代表： unrolled GS for phase retrieval。

展开迭代的通用形式
xk+1 = gθ( xk, y, A )

gθ 把传统更新规则参数化，如步长、松弛因子、投影算子都可学习。 层数 = 迭代次数，通常 5~20 层。

Plug-and-Play 框架

把数据保真步（物理模型）与去噪步（任何去噪器，含 DnCNN）交替执行。 去噪器即"正则项"，无需显式写出 R(x)。这是光学成像中非常实用的混合范式。

17.7 相位恢复的深度学习路线

相位恢复是光学逆问题的"圣杯"——也是 DL 渗透最深的方向。代表性工作：

如何选方法

有真值数据 → 端到端 U-Net；无数据但有物理模型 → DIP / 无训练； 想兼顾可解释与性能 → 深度展开 / Plug-and-Play。 实战中通常先仿真预训练 + 实测微调。

17.8 计算成像：全息、单像素、超分辨

数字全息

干涉记录物波的振幅与相位，DL 用于去孪生像、自动聚焦、相位解包裹。 物理感知风格迁移可在无 GT 下自适应重建（见 2507.00482）。

单像素成像

用空间光调制器做结构化照明，单探测器采集。DL 直接从压缩测量重建图像， 两步训练框架（TST-DL）无需精确物理先验 2001.03493。

超分辨成像

突破衍射极限。SRCNN/RCAN 从低分辨图恢复高频；STORM/PALM 用闪烁定位， DL 加速定位与重建。

散射透过

透过生物组织/毛玻璃成像。U-Net 可学习散斑到图像的映射， 但依赖记忆效应范围，物理约束能提升泛化。

17.9 超表面逆向设计

超表面由亚波长结构阵列构成，可任意调控光的振幅、相位、偏振。 设计问题是：给定目标光学响应，反求结构几何参数。这是高维非凸逆问题。

正演与逆设计
s = fNN(R),    R = FEM(s)

s 是结构参数，R 是光学响应。正演 FEM 仿真慢且不可微； 用代理模型 NN 逼近 FEM，再对 s 做梯度反演。

正向代理模型

CNN/Transformer 从结构预测响应，替代 FEM。加速 10³~10⁶ 倍。 MetaE-former 用邻域注意力代理大尺寸超表面 复现。

逆向网络

直接从目标响应生成结构。常用 GAN 或条件流模型，一次前向即得解， 再用正演仿真验证回代。

伴随优化

对可微正演做梯度下降。配合 SLM 可实时优化相位，抑制旁瓣 SLM 优化。

生成式设计

扩散/扩散模型生成满足响应约束的结构分布，探索设计空间。

17.10 光子神经网络与光学计算

不仅用 DL 设计光学器件，还可以让光本身做计算。光子计算利用光的 高速、并行、低功耗优势，把矩阵乘法搬到光域。

方案原理代表
MZI 网格马赫-曾德干涉仪阵列做酉矩阵 Clements 网络、LuxNAS
衍射神经网络多层相位屏做光场变换 D²NN、兼容学习
微环权重微环谐振器调谐透射率 光子加速器
合成维度脉冲到达时间构造网络层 时序 ONN 2101.08439
光域矩阵乘法
y = W ⊙ x,    Wij = tij · eiφij

tij 为振幅透射率，φij 为相位。 整个矩阵乘法以光速并行完成，延迟仅由光程决定。 难点在制造误差、级联损耗与非线性激活。

17.11 光学生成模型：让光在自由空间完成生成

2025 年 Nature 发表的工作把生成模型直接做在光域：用多层可学习相位屏， 让输入光场经过衍射传播后直接生成目标图像——无需电子计算机推理。 这是"用光计算"的里程碑。

光学生成模型的传播
Eout = AN · PN · ... · A1 · P1 · Ein

Pk 是第 k 层相位屏（可学习），Ak 是自由空间衍射传播。 训练时在仿真中优化相位屏，制造后物理系统一次性完成"生成"。 推理延迟 = 光传播时间（纳秒级）。

复现项目

本人已复现该工作（MATLAB，CPU 可跑），含 15 个脚本、两套原型权重与结果对比： literature-archive / 在线站点。 可对照原文理解光学生成与电子生成的差异。

17.13 动手建议：从入门到精通的路线

  1. 入门（1~2 月）：掌握傅里叶光学（卷积、衍射、菲涅尔/夫琅禾费）， 用 MATLAB/Python 复现一次 GS 相位恢复，理解前向模型。
  2. 进阶（2~4 月）：用 PyTorch 复现一个 U-Net 图像重建任务 （如去噪或超分辨），理解跳跃连接与多尺度。
  3. 深入（4~6 月）：把物理模型嵌入网络——实现 DIP 或深度展开 相位恢复，对比纯端到端的差异。
  4. 精通（6 月+）：选定一个方向（超表面设计 / 光子计算 / 计算成像）， 复现一篇顶刊论文并做改进，公开代码与结果。

本章要点

  • 光学逆问题病态且非线性，DL 的价值在于学习先验或加速逆映射。
  • U-Net 的编码器-解码器 + 跳跃连接天然匹配光学成像的多尺度需求。
  • 无真值数据时，DIP 与深度展开是首选——物理模型比数据更可靠。
  • 超表面逆向设计的核心是"代理模型 + 梯度反演"，替代慢且不可微的 FEM。
  • 光子计算把矩阵乘法搬到光域，光学生成模型让推理延迟达到纳秒级。
  • 光学 DL 必须先懂物理：输入输出、损失、约束都要与前向模型一致。

常见误区

  1. 不懂物理就端到端训练，结果"看起来对"但物理上不成立。
  2. 忽略相位包裹与强度归一化，网络输出范围与物理量不匹配。
  3. 只用 MSE 损失，不加强度一致性约束，泛化到新物理参数时崩溃。
  4. 在仿真数据上训练却不考虑实测噪声、像差、采样误差。
  5. 光子网络只看理论 FLOPs，忽略制造误差与级联损耗。
